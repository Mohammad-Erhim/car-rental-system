## Guards / cross-cutting

`AuthGuard` (HS256 access JWT) · `PermissionsGuard` (role→action, org/location scope) ·
`StepUpGuard` + `@StepUp()` (SRS-SEC-014/018; `auth_challenge` table; `POST /auth/step-up`) ·
`RateLimitGuard` (SEC-015) · `CsrfGuard` (SEC-003) · `IdempotencyInterceptor` (`idempotency_key`
table; `Idempotency-Key` header on commands) · correlation middleware (trace id on every request).

## Async — jobs / workers / events

| Component                           | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Worker process                      | `apps/api/src/worker.ts` — separately runnable. One BullMQ queue `housekeeping` + `housekeeping-dlq`.                                                                                                                                                                                                                                                                                                                                                                                                |
| Repeatable job `reap` (every 5 min) | deletes expired `auth_challenge` + `idempotency_key`; flips `rental` `active`→`overdue` past `scheduled_return_at` (FR-RNT-014); **logs** `outboxBacklog` count.                                                                                                                                                                                                                                                                                                                                     |
| Manual equivalent                   | `POST /api/v1/ops/rentals/overdue-sweep` (same overdue logic, on demand).                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Dead-letter                         | `worker.on('failed')` → `housekeeping-dlq` after attempts exhausted.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Transactional outbox                | `OutboxService.emit()` writes `outbox_message` in the aggregate tx. **No relay/dispatcher — `S7-DEF-002`.** Events emitted: `reservation.{confirmed,modified,cancelled}.v1`, `payment.captured.v1`, `rental.{started,closed}.v1`, `case.opened.v1`, `report.delivery.v1`, `pricing.rate_plan.{created,updated,published}`, `catalogue.{category.created,category.updated,changed.v1}`, `lookup.{invalidated.v1,value.created,value.updated}`, `config.translation.published`, `iam.profile.updated`. |
| In-process cache invalidation       | `common/cache/cache-bus.ts` (`CacheBus`) — used by lookup / translation / catalogue / iam services. Independent of the outbox; this is why "edit a lookup, selector updates, no redeploy" works.                                                                                                                                                                                                                                                                                                     |
| Notifications                       | `notify.service.ts` — `NotificationPort` + local `outbox` mail driver; renders published `template` rows; dev viewer at `/dev/mail`. Marks its own `notification` rows `sent` directly (dev driver).                                                                                                                                                                                                                                                                                                 |
| Scheduled reports                   | `report_schedule` rows; `POST /ops/reports/schedules/{id}/send` is the manual trigger a scheduler tick would call (owner re-auth → skip+pause+`last_skip_reason`). No live scheduler loop — by design (manual/tick).                                                                                                                                                                                                                                                                                 |
