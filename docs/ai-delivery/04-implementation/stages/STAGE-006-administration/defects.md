# STAGE-006 — defects

All found and fixed within the stage. No open defects; no known critical/high.

| ID      | Severity | Description                                                                                                                                                                                                                                                                                                    | Status | Resolution                                                                                                                                                                                                                       |
| ------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-006-1 | Low      | `POLICY_DEFAULTS` was typed `Record<string, Record<string, number>>`; under `noUncheckedIndexedAccess` the `preview()` method's `POLICY_DEFAULTS.cancellation.lateFeeBps` etc. were `possibly undefined` → `tsc` TS18048.                                                                                      | Fixed  | Introduced an explicit `PolicyDefaults` interface with named keys (`cancellation`, `fuel_rate`) **and** a string index signature, so named access is defined while `policy(key, field)` can still index by an arbitrary string.  |
| D-006-2 | Medium   | The `config_version` table spread `...auditColumns` (which defines the optimistic-lock `version` column) and then also declared a semantic `version: integer('config_version')`. The second key overwrote the first in the object literal, silently **dropping the standard `version` column** for this table. | Fixed  | Renamed the semantic column to `revision` (DB column `revision`; unique index `config_version_kind_key_rev_unq`). `auditColumns.version` is restored. API + web now speak `revision`. Migration `0006` regenerated (18 columns). |
| D-006-3 | Medium   | `report.service.run()` `revenue_by_category` built its scope filter as `` sql`${reservation.pickupLocationCode} in ${scope}` `` with a JS array. Drizzle does not expand an array inside a raw `sql` template, so the `IN` list would have been a single bad param → wrong / empty rows for a scoped operator. | Fixed  | Rebuilt with `and(inArray(reservation.state, [...]), inArray(reservation.pickupLocationCode, scope))`, matching the `reservations_by_state` case. Also parenthesised `(count(*) filter (where …))::int` in the `refunds` case.   |
| D-006-4 | Low      | The STAGE-006 E2E signed out on `/ops/config` then signed back in as a second publisher; `RequireAuth` had stashed `/ops/config` as the return-to, so the post-login redirect landed there, not `/ops` — the helper's `expect(page).toHaveURL(/\/ops$/)` failed on tablet + laptop.                            | Fixed  | `signInStaff` now `waitForURL`s for "an `/ops` path that is not `/sign-in`" instead of an exact match. Also added an `aria-label` to the icon-only ops "Sign out" button so it is addressable at every breakpoint.               |
