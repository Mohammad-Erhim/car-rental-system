# STAGE-003 — defects

All found and fixed within the stage. No open defects; no known critical/high.

| ID      | Severity | Description                                                                                                                                                                                                                   | Status | Resolution                                                                                                                                                                                                                                                                                                                                                                     |
| ------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| D-003-1 | High     | Two concurrent `confirm()` for the same quote both passed the "reservation exists?" pre-check and raced to `INSERT reservation` / `INSERT payment_intent` — one hit a unique-constraint violation and returned a raw error.   | Fixed  | `payment_intent` insert is `onConflictDoNothing` on `(reservationReference, purpose)` then re-selects (returns the settled intent if the other call already authorized/captured); the `reservation` insert catches `23505` and returns the winning row. The deterministic `RES-<sha256(quoteRef)[:8]>` reference keeps the payment idempotency key identical for both callers. |
| D-003-2 | Medium   | The web `useConfirmBooking` hook was `anonymous: true`, so a **signed-in** customer's booking was created as a guest (`accountId: null`) and never appeared under `/bookings/mine`.                                           | Fixed  | Dropped `anonymous` — `apiFetch` attaches the bearer when signed in (ties the reservation to the account) and still works token-less for genuine guest checkout (the endpoint is `@OptionalAuth()`).                                                                                                                                                                           |
| D-003-3 | Low      | The E2E console guard flagged the browser's automatic `Failed to load resource: … status of 422` message for the deliberately-declined test card — the `response`-level allow-list did not cover the `console`-level message. | Fixed  | `_helpers.ts` refactored to share one `isExpectedNegative(url, status)` predicate used by both the `response` and `console` handlers; the console handler parses `status of NNN` + `msg.location().url`.                                                                                                                                                                       |
| D-003-4 | Low      | Payment error codes `payment_failed` / `provider_unavailable` were used but are not in the stable error taxonomy.                                                                                                             | Fixed  | Timeout → `provider_timeout` (504); decline / capture-failure → `business_rule_violation` with a `reason` param (a declined card is a business outcome, not a system fault).                                                                                                                                                                                                   |
| D-003-5 | Low      | `booking.controller.ts` import order (`node:crypto` after `@carrental/contracts`) failed `-r lint`.                                                                                                                           | Fixed  | `eslint --fix` + prettier.                                                                                                                                                                                                                                                                                                                                                     |
